# BrandFlow CRM

**CRM for clothing and merchandise brands.**

BrandFlow is a CRM designed to help small clothing brands manage their business operations in one place — from customer orders and inventory to production and delivery.

### 🎯 About the Project

The platform is designed for clothing brands that:

- Receive orders through Instagram.
- Manage clothing inventory and product prints.
- Organize printing and production processes.
- Track customer orders and payments.
- Manage shipments via Nova Poshta.

### 🛠 Tech Stack

- **Frontend:** React, Vite, TypeScript
- **Backend:** NestJS
- **Database:** PostgreSQL
- **ORM:** TypeORM
- **Infrastructure:** Docker, Docker Compose

### 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd BrandFlowCRM
   ```

2. Configure your environment variables (`.env`).

3. Start the application:
   ```bash
   docker compose up --build
   ```
